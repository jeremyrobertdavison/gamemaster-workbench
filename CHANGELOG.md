# Changelog

## 1.0.0

Initial public release.

- GM-only system-agnostic Workbench application
- Five-column drag-and-drop Kanban board
- Detailed cards with comments, checklists, tags, priority, prep date, and session assignment
- Linked Foundry documents and directory context-menu card creation
- Session Prep filtering and completion count
- Multi-note private rich-text prep notebook
- Search and board filters
- Card duplication, archiving, restoring, and deletion
- Per-GM user-scoped persistence in Foundry VTT v13
